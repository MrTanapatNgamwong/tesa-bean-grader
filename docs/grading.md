# เกณฑ์เกรด A/B/C

## หลักคิด

เกรดตัดจาก **ทั้งตัวอย่าง (ล็อต)** ไม่ใช่ทีละเม็ด ใช้ระบบ full defect ของ SCA / CQI (Fine Robusta) เพราะครอบคลุมครบ 7 คลาสและให้น้ำหนักตามความร้ายแรง

| คลาส | หมวด SCA | กี่เม็ด = 1 full defect |
|---|---|---|
| full_black | 1 | 1 |
| hull_husk | 2 | 5 (ถ้าหมายถึงผลแห้งทั้งลูก → หมวด 1, 1 เม็ด) |
| shell, broken, parchment, immature | 2 | 5 |
| good | — | 0 |

```
full_defects          = Σ (จำนวนเม็ดคลาส ÷ กี่เม็ดต่อ 1 full defect)
full_defects_per_350g = full_defects / total_beans × 2,160   # โรบัสต้า ~16.2 g / 100 เมล็ด
```

| เกรด | full defects / 350 g | เทียบสากล |
|---|---|---|
| A | ≤ 8 | Specialty + Premium |
| B | 9–23 | Exchange |
| C | ≥ 24 | Below standard + Off grade |

เทียบเป็นสัดส่วน: A ต้องมีเมล็ดเสียหมวด 2 ไม่เกิน ~1.85% (หรือเมล็ดดำ ~0.37%) · B ไม่เกิน ~5.32% (เมล็ดดำ ~1.06%)

## ตัวอย่าง (กอง 60 เม็ด)

| ในกอง | full defects | / 350 g | เกรด |
|---|---|---|---|
| broken 1 | 0.2 | 7.2 | A |
| broken 3 | 0.6 | 21.6 | B |
| broken 3 + immature 2 | 1.0 | 36.0 | C |
| full_black 1 | 1.0 | 36.0 | C |

## ข้อควรรู้

- เกณฑ์เข้มกับเมล็ดดำมาก (ตามมาตรฐาน)
- ภาพที่มีเมล็ดน้อย ผลแกว่งง่าย → รวมหลายภาพเป็นล็อต · เตือนเมื่อ < 30 เม็ด
- เกรดทางกายภาพเท่านั้น · Fine Robusta จริงต้องผ่านการชิม ≥ 80 คะแนน
- เกณฑ์ทั้งหมดอยู่ใน `grader/grading.yaml` แก้ได้โดยไม่แตะโค้ด

## มาตรฐานไทยที่เกี่ยวข้อง

มกษ. 5700-2561 (เมล็ดกาแฟโรบัสตา) เป็นแบบผ่าน/ไม่ผ่านตาม % โดยมวล เช่น เมล็ดดำ ≤ 2%, ชิ้นแตก ≤ 2%, ข้อบกพร่องรวม ≤ 7%
